### 🚀 About Me

I'm a **Computer Engineering** graduate from Tekirdağ Namık Kemal University who
enjoys building applications across **mobile and backend development**. I focus on understanding how systems work,
writing maintainable code, and choosing the right tools for each project.
I'm also expanding my skills in **data analysis and AI**.

- 🛠️ **Backend & mobile:** Java & Spring Boot on the backend, Flutter & SwiftUI on mobile
- 🔐 **Interested in** authentication systems, clean architecture, and secure API design
- ✅ **Focus on quality:** using AI-assisted tools while paying attention to clean code and testing
- 🌱 **Always learning:** currently exploring data & AI with Python through a hands-on research project
- 🌐 Portfolio and projects: **[batuhangozegu.com](https://batuhangozegu.com)**
